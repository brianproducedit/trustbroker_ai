# TrustBroker AI — Web app

React frontend for TrustBroker AI. See the **root** [`README.md`](../README.md) and [`docs/TrustBroker_AI_Hackathon_Roadmap.md`](../docs/TrustBroker_AI_Hackathon_Roadmap.md).

## Stack

React 19, TypeScript, Vite, Tailwind CSS, AG Grid Community, PayPal JS SDK, Zustand, Supabase Auth.

## Run

```bash
npm install
npm run dev
```

## Routes

| Path | Description |
|---|---|
| `/` | Public landing |
| `/how-it-works` | Client and freelancer lifecycle |
| `/for-clients` | Client product page |
| `/for-freelancers` | Freelancer product page |
| `/sign-in` | Sign in (choose client or freelancer workspace) |
| `/sign-up` | Create account (primary workspace required) |
| `/dashboard` | Signed-in workspace |
| `/developers` | API overview |
